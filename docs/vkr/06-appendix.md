# Приложения

Состав приложений определён заданием на ВКР: листинг программного кода
(около 400 операторов) и объёмные графические материалы.

## Приложение А — Листинги программного кода

В приложение включается распечатка отлаженных расчётных модулей. По
заданию объём листинга — около 400 операторов языка высокого уровня.
Рекомендуемый набор модулей (суммарно покрывает расчётную логику
приложения; ссылки — на файлы репозитория):

- [`finance_transaction_usecases.dart`](../../lib/domain/usecases/finance_transaction_usecases.dart) —
  сценарии операций: валидация и оркестрация сохранения дохода, расхода
  и перевода;
- [`transfer_rate_rule.dart`](../../lib/domain/services/transfer_rate_rule.dart) —
  правило расчёта курса мультивалютного перевода;
- [`account_balance_rule.dart`](../../lib/domain/services/account_balance_rule.dart) —
  правило пересчёта остатка счёта;
- [`debt_balance_rule.dart`](../../lib/domain/services/debt_balance_rule.dart) —
  правило расчёта остатка долга контрагента;
- [`analytics_rule.dart`](../../lib/domain/services/analytics_rule.dart) —
  правило агрегатов аналитики (месячный срез, годовой тренд);
- [`csv_journal_exporter.dart`](../../lib/domain/services/csv_journal_exporter.dart) —
  формирование CSV-экспорта журнала операций.

Листинг оформляется на исходном языке Dart с сохранением комментариев
и нумерации строк.
