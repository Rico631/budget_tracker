# ВКР — описательная часть

Документы раздела сформированы по шаблону задания на выпускную квалификационную
работу «Разработка мобильного приложения для управления личными финансами
на примере ПАО «Сбербанк»» и описывают проект [budget_tracker](../../README.md)
в терминах, принятых в задании: аналитическая часть, проектная часть,
экономическое обоснование.

Раздел — текстовая основа для переноса в тело ВКР: структура и нумерация
разделов повторяют шаблон задания, а фактический материал опирается на
реализованный код и документацию репозитория.

## Связь с остальной документацией

Описательная часть не дублирует проектную документацию, а ссылается на неё:

- решения по продукту и архитектуре — [docs/adr/](../adr/), начиная с [ADR-0001](../adr/0001-budget-tracker-concept-and-ux.md);
- фактическая архитектура (C4), схема БД, механизмы — [docs/architecture/ARCHITECTURE.md](../architecture/ARCHITECTURE.md);
- справочники банков, категорий и валют — [docs/reference-data/](../reference-data/);
- требования и изменения — [openspec/](../../openspec/).

## Пометки для доработки

- Показатели деятельности ПАО «Сбербанк» в разделе 1.1 приведены
  ориентировочно и требуют сверки с годовым отчётом банка за актуальный
  период; места сверки помечены в тексте.
- Расчётные цифры главы 3 даны как методический пример с параметрами по
  умолчанию; перед включением в ВКР их следует заменить фактическими
  трудозатратами и ставками.
- Скриншоты экранных форм приложения — реальные изображения в
  [assets/images/examples](../../assets/images/examples/), включены в раздел
  2.4 и корневой README. Рисунки IDEF0 и организационной структуры
  представлены описаниями и схемами Mermaid; в текст ВКР они переносятся
  как рисунки с подписями.
