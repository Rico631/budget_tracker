# ADR-0002: Валюта по умолчанию для нового счета

- **Статус:** Accepted
- **Дата:** 2026-09-26
- **Область:** продукт, счета, валюта, локализация интерфейса
- **Связанные артефакты:** `docs/adr/0001-budget-tracker-concept-and-ux.md`, `openspec/specs/first-run-bootstrap/spec.md`, `openspec/changes/2026-09-26-add-accounts-and-navigation/specs/accounts-overview/spec.md`
- **Закрывает:** отложенный вопрос ADR-0001 «Валюта по умолчанию для нового счета и поведение при смене языка интерфейса»

## Контекст

ADR-0001 не фиксирует, какая валюта подставляется в форме создания счета: решение 2.1 задает только то, что каждый счет ведется в своей валюте и итоги по валютам не складываются, а решение 2.2 определяет начальный остаток как данные счета, не создающие доход. Вопрос о валюте по умолчанию остался в разделе «Отложенные вопросы» ADR-0001 как незакрытая ветвь.

Изменение `2026-09-26-add-accounts-and-navigation` реализует создание счета и использует справочник валют из 164 позиций ISO 4217. Справочник доступен только для чтения, поэтому валюта счета выбирается из списка. Если форма не подставляет валюту, самое частое действие — создание счета в своей обычной валюте — требует обязательного выбора из длинного списка.

## Решения

| №   | Вопрос                                   | Решение                                                                                             | Обоснование и следствие                                                                                                                 |
| --- | ---------------------------------------- | --------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 2.1 | Валюта по умолчанию для нового счета     | Валюта по умолчанию зависит от локали интерфейса: `ru` -> `RUB`, любая другая поддерживаемая локаль -> `USD` | Самый частый сценарий создания счета заполнен заранее, а пользователь сохраняет возможность изменить выбор до сохранения                  |
| 2.2 | Поведение при смене языка интерфейса     | Смена языка интерфейса не изменяет валюты созданных счетов                                          | Валюта счета — данные счета, а не следствие текущей локали; пересчет и конвертация сумм не выполняются (решение 2.1 ADR-0001)            |

Правило локали формулируется для поддерживаемых локалей приложения (`ru`, `en`). Неподдерживаемая локаль устройства сводится к русскому fallback-языку (capability `app-foundation`), поэтому для нее действует `RUB`; значение `USD` применяется для остальных поддерживаемых локалей, то есть для `en`.

## Рассмотренные варианты

- **Отсутствие предварительного выбора валюты** — отклонено: добавляет обязательный шаг в самом частом сценарии и оставляет отложенный вопрос ADR-0001 нерешенным.
- **Валюта по умолчанию из настроек приложения** — отклонено: ADR-0001 не вводит такой настройки, а таблица `AppSettings` хранит только признак завершенного первого запуска.
- **Валюта по умолчанию, закрепленная за книгой учета** — отклонено: ADR-0001 не описывает валюту книги, а мультивалютность реализована на уровне счета (решение 2.1).

## Последствия

- Форма создания счета показывает валюту по умолчанию, выбранную по локали интерфейса, с возможностью изменить ее через справочник валют.
- Смена языка интерфейса не переписывает данные созданных счетов: валюта остается той, что была выбрана при создании или изменении счета.
- Валюта счета без операций может быть изменена вручную; для счета с операциями смена валюты запрещена (ADR 4.4 и решение 2.1 ADR-0001).
- Правило помещается в доменный слой (`AccountUseCases.defaultCurrencyCodeFor`) и не зависит от UI, поэтому его можно переиспользовать в других формах, например при импорте или массовом создании счетов.

## Связь с ADR-0001

- ADR-0001 не переписывается и не заменяется: ни одно из его 29 решений не отменяется и не уточняется, статус ADR-0001 остается `Accepted`.
- Формулировка `Supersedes: ADR-0001` не применяется: запись не отменяет и не заменяет решения ADR-0001, а закрывает одну ветвь из раздела «Отложенные вопросы» ADR-0001.
- Решения ADR-0001, затрагиваемые этой записью, сохраняются без изменений: мультивалютность счетов и раздельные итоги без конвертации (2.1), начальный остаток как данные счета (2.2), тип операции как источник цвета (9.1).
- Прочие ветви раздела «Отложенные вопросы» ADR-0001 (доступность цветов, экспорт и резервная копия, правила удаления категорий, удаление книги с историей, отображение курса перевода) остаются незакрытыми и этой записью не затрагиваются.
