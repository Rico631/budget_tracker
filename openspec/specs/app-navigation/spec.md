# app-navigation Specification

## Purpose

Capability описывает навигационную оболочку приложения: основные разделы доступны через четыре нижние вкладки, активный раздел определяет содержимое экрана, а разделы, ещё не реализованные в поставке, показывают контролируемое состояние вместо пустых данных.

## Requirements

### Requirement: Основные разделы доступны через четыре нижние вкладки

Система MUST предоставлять плоскую навигацию из четырех нижних вкладок: «Счета», «Операции», «Аналитика» и «Настройки». Стартовым разделом при запуске приложения MUST быть раздел «Счета». Настройки MUST быть отдельным четвертым разделом и MUST NOT размещаться внутри другого раздела.

#### Scenario: Первый показ приложения

- **WHEN** пользователь открывает приложение после завершения инициализации первого запуска
- **THEN** отображается навигация из четырех нижних вкладок
- **AND** активной вкладкой является «Счета»
- **AND** содержимое соответствует разделу «Счета»

#### Scenario: Переключение раздела

- **WHEN** пользователь выбирает другую нижнюю вкладку
- **THEN** активной становится выбранная вкладка
- **AND** отображается содержимое выбранного раздела
- **AND** четыре вкладки остаются доступными

#### Scenario: Настройки доступны из навигации напрямую

- **WHEN** пользователь хочет открыть настройки приложения
- **THEN** настройки открываются отдельной вкладкой
- **AND** для доступа к настройкам не требуется проходить через разделы «Счета», «Операции» или «Аналитика»

### Requirement: Действие добавления размещается по правилу раздела

Навигационная оболочка MUST предоставлять действие добавления операции на разделах «Счета» и «Операции» и MUST NOT показывать действие добавления на разделах «Аналитика» и «Настройки». На разделе «Счета» дополнительно MUST быть доступно действие добавления счета. Действия добавления внутри подэкранов раздела «Настройки» MUST NOT отображаться оболочкой и MUST отображаться самими подэкранами. Действие добавления операции и действие добавления счета MUST NOT отображаться в подэкране операций категории раздела «Аналитика»: этот подэкран показывает уже введенные операции и их изменение, а не создание.

#### Scenario: Действие добавления на разделе «Счета»

- **WHEN** активен раздел «Счета»
- **THEN** доступно действие добавления операции
- **AND** доступно действие добавления счета

#### Scenario: Действие добавления на разделе «Операции»

- **WHEN** активен раздел «Операции»
- **THEN** доступно действие добавления операции
- **AND** действие добавления счета недоступно

#### Scenario: Действие добавления на разделах аналитики и настроек

- **WHEN** активен раздел «Аналитика» или «Настройки»
- **THEN** действие добавления операции или счета отсутствует
- **AND** навигация и содержимое раздела остаются доступными

#### Scenario: Действие добавления на подэкране справочника

- **WHEN** пользователь открыл подэкран «Категории» или «Банки» из раздела «Настройки»
- **THEN** действие добавления записи доступно в этом подэкране
- **AND** оболочка приложения по-прежнему не показывает действий добавления на разделе «Настройки»

#### Scenario: Действие добавления на подэкране операций категории

- **WHEN** пользователь открыл подэкран операций категории из раздела «Аналитика»
- **THEN** действие добавления операции и действие добавления счета отсутствуют
- **AND** действия изменения и удаления операции остаются доступными

#### Scenario: Действие добавления на разделе без содержимого

- **WHEN** активен раздел, содержимое которого ещё не реализовано
- **THEN** действие добавления не отображается
- **AND** отсутствие действия не мешает переходу на другие вкладки

### Requirement: Раздел «Настройки» содержит управление справочниками

Раздел «Настройки» MUST предоставлять пользователю доступ к управлению справочниками категорий и банков. Раздел MUST показывать список пунктов «Категории» и «Банки», а выбор пункта MUST открывать соответствующий подэкран. Подэкран MUST открываться поверх раздела с собственным заголовком и MUST позволять вернуться в раздел «Настройки» без потери выбранной вкладки навигации.

#### Scenario: Список пунктов раздела «Настройки»

- **WHEN** пользователь открывает раздел «Настройки»
- **THEN** отображаются пункты «Категории» и «Банки»
- **AND** каждый пункт доступен для выбора
- **AND** нижняя навигация из четырех вкладок остается доступной

#### Scenario: Переход в подэкран справочника

- **WHEN** пользователь выбирает пункт «Категории» или «Банки»
- **THEN** открывается подэкран выбранного справочника
- **AND** подэкран показывает записи справочника своей книги или приложения
- **AND** заголовок подэкрана соответствует выбранному справочнику

#### Scenario: Возврат из подэкрана

- **WHEN** пользователь возвращается из подэкрана справочника
- **THEN** отображается раздел «Настройки» со списком пунктов
- **AND** активной вкладкой остается «Настройки»

#### Scenario: Категории разделены по типам

- **WHEN** пользователь открывает подэкран «Категории»
- **THEN** категории доходов и категории расходов отображаются раздельно по типу
- **AND** категории типа `transfer` в списке отсутствуют, поскольку перевод не имеет категории

### Requirement: Раздел «Настройки» содержит доступ к экспорту и базам данных

Раздел «Настройки» MUST предоставлять пункт-хаб «Экспорт и базы данных». Выбор пункта MUST открывать подэкран с действиями выгрузки журнала в CSV, создания резервной копии, восстановления из копии и пунктом открытия списка баз данных. Подэкран MUST открываться поверх раздела с собственным заголовком и MUST позволять вернуться в раздел «Настройки» без потери выбранной вкладки навигации. Действие добавления оболочки на подэкранах раздела MUST NOT отображаться.

#### Scenario: Пункт-хаб в разделе «Настройки»

- **WHEN** пользователь открывает раздел «Настройки»
- **THEN** отображается пункт «Экспорт и базы данных»
- **AND** пункт доступен для выбора наряду с пунктами справочников

#### Scenario: Переход в подэкран экспорта и баз

- **WHEN** пользователь выбирает пункт «Экспорт и базы данных»
- **THEN** открывается подэкран с действиями выгрузки журнала, создания резервной копии, восстановления из копии и открытия списка баз
- **AND** заголовок подэкрана соответствует выбранному пункту

#### Scenario: Возврат из подэкрана экспорта и баз

- **WHEN** пользователь возвращается из подэкрана «Экспорт и базы данных»
- **THEN** отображается раздел «Настройки» со списком пунктов
- **AND** активной вкладкой остаётся «Настройки»
