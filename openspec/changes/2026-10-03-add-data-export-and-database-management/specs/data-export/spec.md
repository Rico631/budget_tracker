# Spec Delta

## Purpose

Выгрузка журнала операций активной книги в один CSV-файл с человекочитаемыми колонками и профилем файла, зависящим от выбранного языка.

## ADDED Requirements

### Requirement: Выгрузка журнала операций в CSV

Система MUST выгружать журнал операций активной книги в один CSV-файл. Файл MUST содержать все операции книги, включая операции архивированных счетов. Каждая операция MUST занимать одну строку файла. Выгрузка MUST быть односторонней: импорт CSV-файла обратно в приложение MUST NOT поддерживаться.

#### Scenario: Успешная выгрузка журнала

- **WHEN** пользователь запускает выгрузку журнала и подтверждает место сохранения файла
- **THEN** создаётся один CSV-файл с журналом операций активной книги
- **AND** файл содержит по одной строке на каждую операцию книги

#### Scenario: Выгрузка полного журнала

- **WHEN** в книге есть операции, включая операции архивированных счетов
- **THEN** в файл попадают все операции книги
- **AND** операции архивированных счетов включаются в выгрузку

#### Scenario: Пустой журнал

- **WHEN** в активной книге нет ни одной операции
- **THEN** создаётся CSV-файл, содержащий строку заголовков
- **AND** строк данных в файле нет

### Requirement: Состав строки журнала

Система MUST формировать строку операции из колонок: `occurred_at`, `kind`, `account`, `currency`, `category`, `note`, `amount`, `to_account`, `to_currency`, `to_amount`. `kind` MUST принимать локализованную метку типа операции. У дохода и расхода колонки `to_account`, `to_currency`, `to_amount` MUST быть пустыми. У перевода колонка `category` MUST быть пустой. Суммы MUST быть знаковыми: доход — положительная сумма, расход — отрицательная сумма, перевод — отрицательная сумма списания по счету-источнику и положительная сумма зачисления по счету-получателю. Заметка MUST быть необязательной и допускать пустое значение.

#### Scenario: Строка дохода

- **WHEN** выгружается операция-доход
- **THEN** строка содержит счет, валюту, категорию и положительную сумму
- **AND** колонки `to_account`, `to_currency`, `to_amount` пустые

#### Scenario: Строка расхода

- **WHEN** выгружается операция-расход
- **THEN** строка содержит счет, валюту, категорию и отрицательную сумму
- **AND** колонки `to_account`, `to_currency`, `to_amount` пустые

#### Scenario: Строка перевода

- **WHEN** выгружается операция-перевод
- **THEN** строка содержит счет-источник с отрицательной суммой списания и счет-получатель с положительной суммой зачисления
- **AND** колонка `category` пустая

### Requirement: Профиль файла зависит от выбранного языка

Система MUST позволять пользователю выбрать язык выгрузки из поддерживаемых языков приложения (`ru`, `en`); по умолчанию MUST использоваться текущий язык приложения. От выбранного языка MUST зависеть: десятичный знак (для `ru` — запятая, для `en` — точка), разделитель колонок (для `ru` — `;`, для `en` — `,`), заголовки колонок и метки типа операции. Кодировка файла MUST быть `UTF-8` с BOM. Даты MUST записываться в формате ISO `yyyy-MM-dd HH:mm:ss`. Суммы MUST записываться без разделителей групп разрядов.

#### Scenario: Выгрузка на русском языке

- **WHEN** пользователь выбирает язык выгрузки `ru`
- **THEN** заголовки колонок и метки типа операции записываются на русском языке
- **AND** десятичный знак — запятая, а разделитель колонок — `;`

#### Scenario: Выгрузка на английском языке

- **WHEN** пользователь выбирает язык выгрузки `en`
- **THEN** заголовки колонок и метки типа операции записываются на английском языке
- **AND** десятичный знак — точка, а разделитель колонок — `,`

#### Scenario: Язык выгрузки по умолчанию

- **WHEN** пользователь запускает выгрузку, не меняя язык
- **THEN** используется язык приложения

### Requirement: Ошибка выгрузки не изменяет данные

Если выгрузку невозможно завершить, система MUST NOT изменять данные приложения и MUST показывать пользователю сообщение о неуспешной выгрузке.

#### Scenario: Отказ в диалоге сохранения

- **WHEN** пользователь отменяет диалог выбора места сохранения файла
- **THEN** файл не создаётся
- **AND** данные приложения не изменяются

#### Scenario: Ошибка записи файла

- **WHEN** запись CSV-файла завершается ошибкой
- **THEN** пользователю показывается сообщение о неуспешной выгрузке
- **AND** данные приложения не изменяются
