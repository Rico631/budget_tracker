# Spec Delta

## MODIFIED Requirements

### Requirement: Текущий остаток счета рассчитывается из начального остатка и операций

Система MUST рассчитывать текущий остаток счета как начальный остаток счета плюс влияние операций по этому счету. Доход MUST увеличивать остаток, расход MUST уменьшать остаток, перевод MUST уменьшать остаток счета-источника и увеличивать остаток целевого счета. Для перевода между счетами в разных валютах остаток счета-источника MUST уменьшаться на сумму списания, а остаток целевого счета MUST увеличиваться на сумму зачисления; суммы разных валют MUST NOT складываться и MUST NOT конвертироваться в остатке счета. Начальный остаток MUST NOT создавать операцию дохода и MUST NOT учитываться как доход.

#### Scenario: Счет без операций

- **WHEN** счет создан с начальным остатком, и по нему нет операций
- **THEN** текущий остаток счета равен начальному остатку
- **AND** операция дохода для начального остатка не создается

#### Scenario: Доход и расход по счету

- **WHEN** по счету зарегистрированы доход и расход
- **THEN** текущий остаток увеличивается на сумму дохода
- **AND** текущий остаток уменьшается на сумму расхода

#### Scenario: Перевод между счетами одной книги

- **WHEN** между двумя счетами одной валюты зарегистрирован перевод
- **THEN** остаток счета-источника уменьшается на сумму перевода
- **AND** остаток целевого счета увеличивается на ту же сумму

#### Scenario: Перевод между счетами разных валют

- **WHEN** между двумя счетами разных валют зарегистрирован перевод с суммой списания и суммой зачисления
- **THEN** остаток счета-источника уменьшается на сумму списания в его валюте
- **AND** остаток целевого счета увеличивается на сумму зачисления в его валюте
- **AND** суммы разных валют не складываются между собой

#### Scenario: Нулевой и отрицательный остаток

- **WHEN** текущий остаток счета равен нулю или отрицателен
- **THEN** остаток отображается явно, включая знак
- **AND** отрицательный остаток не скрывается и не заменяется нулем

### Requirement: Счет с историей архивируется вместо удаления

Счет, по которому зарегистрированы операции, MUST архивироваться вместо безвозвратного удаления. Безвозвратное удаление MUST быть доступно только для счета без связанных операций. Архивирование MUST сохранять операции счета в истории книги: операции архивированного счета MUST оставаться доступными в истории книги вместе с названием этого счета, хотя сам счет MUST NOT отображаться в списке активных счетов.

#### Scenario: Попытка удалить счет с операциями

- **WHEN** пользователь пытается удалить счет, по которому зарегистрированы операции
- **THEN** система не удаляет счет безвозвратно
- **AND** пользователю предлагается архивирование счета
- **AND** операции счета сохраняются в истории

#### Scenario: Архивирование счета

- **WHEN** пользователь архивирует счет
- **THEN** счет получает признак архивного
- **AND** счет исчезает из списка активных счетов
- **AND** операции счета остаются доступными в истории книги

#### Scenario: Операции архивного счета в истории книги

- **WHEN** пользователь просматривает историю операций книги после архивирования счета
- **THEN** операции архивированного счета отображаются в истории с названием этого счета
- **AND** остатки остальных счетов не изменяются из-за архивирования

#### Scenario: Удаление счета без операций

- **WHEN** пользователь удаляет счет, по которому нет операций
- **THEN** счет удаляется безвозвратно
- **AND** другие счета и операции книги не изменяются
