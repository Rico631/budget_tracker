# Spec Delta

## MODIFIED Requirements

### Requirement: Состав строки журнала

Система MUST формировать строку операции из колонок: `occurred_at`, `kind`, `account`, `currency`, `category`, `counterparty`, `note`, `amount`, `to_account`, `to_currency`, `to_amount`. `kind` MUST принимать локализованную метку типа операции. У дохода и расхода колонки `to_account`, `to_currency`, `to_amount` MUST быть пустыми. У перевода колонка `category` MUST быть пустой. Колонка `counterparty` MUST содержать наименование контрагента для операции с привязкой к контрагенту и MUST быть пустой для операции без привязки и для перевода. Суммы MUST быть знаковыми: доход — положительная сумма, расход — отрицательная сумма, перевод — отрицательная сумма списания по счету-источнику и положительная сумма зачисления по счету-получателю. Заметка MUST быть необязательной и допускать пустое значение.

#### Scenario: Строка дохода

- **WHEN** выгружается операция-доход
- **THEN** строка содержит счет, валюту, категорию и положительную сумму
- **AND** колонки `to_account`, `to_currency`, `to_amount` пустые

#### Scenario: Строка расхода

- **WHEN** выгружается операция-расход
- **THEN** строка содержит счет, валюту, категорию и отрицательную сумму
- **AND** колонки `to_account`, `to_currency`, `to_amount` пустые

#### Scenario: Строка перевода

- **WHEN** выгружается операция-перевод
- **THEN** строка содержит счет-источник с отрицательной суммой списания и счет-получатель с положительной суммой зачисления
- **AND** колонки `category` и `counterparty` пустые

#### Scenario: Строка операции с контрагентом

- **WHEN** выгружается операция дохода или расхода, привязанная к контрагенту
- **THEN** колонка `counterparty` содержит наименование контрагента
- **AND** остальные колонки заполнены по общим правилам типа операции

#### Scenario: Строка операции без контрагента

- **WHEN** выгружается операция дохода или расхода без привязки к контрагенту
- **THEN** колонка `counterparty` пустая
- **AND** остальные колонки заполнены по общим правилам типа операции
