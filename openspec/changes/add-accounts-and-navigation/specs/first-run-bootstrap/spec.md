# Spec Delta

## ADDED Requirements

### Requirement: После инициализации предлагается добавить первый счет

После успешного завершения инициализации первого запуска приложение MUST предлагать пользователю добавить первый счет, если в книге по умолчанию нет ни одного активного счета. Пользователь MUST иметь возможность пропустить этот шаг, и пропуск MUST NOT блокировать работу приложения и MUST NOT считаться ошибкой инициализации.

#### Scenario: Предложение при пустой книге

- **WHEN** инициализация первого запуска завершилась успешно, и в книге нет ни одного активного счета
- **THEN** приложение показывает предложение добавить первый счет
- **AND** предложение содержит действие перехода к созданию счета и действие пропуска

#### Scenario: Пропуск добавления первого счета

- **WHEN** пользователь пропускает предложение добавить первый счет
- **THEN** приложение переходит к главному экрану со списком счетов
- **AND** приложение остается работоспособным без созданных счетов
- **AND** признак завершенного первого запуска остается установленным

#### Scenario: Книга уже содержит активные счета

- **WHEN** приложение запускается, и в книге уже есть хотя бы один активный счет
- **THEN** предложение добавить первый счет не показывается
- **AND** приложение сразу показывает список счетов

#### Scenario: Инициализация завершилась ошибкой

- **WHEN** инициализация первого запуска завершилась ошибкой
- **THEN** предложение добавить первый счет не показывается
- **AND** приложение показывает контролируемое состояние ошибки инициализации

#### Scenario: Отказ от предложения не удаляет данные первого запуска

- **WHEN** пользователь пропустил предложение и закрыл приложение
- **THEN** при следующем запуске ранее созданные книга, категории и справочники сохраняются
- **AND** повторное наполнение справочников не выполняется
