# Spec Delta

## ADDED Requirements

### Requirement: Приложение имеет собственную иконку запуска

Приложение MUST устанавливаться и отображаться с собственным знаком вместо стандартной иконки Flutter. Иконка запуска MUST отображаться на домашнем экране и в списке запущенных приложений Android, в ярлыке web-сборки и в ярлыке исполняемого файла Windows. Один и тот же знак MUST использоваться на всех поддерживаемых платформах.

#### Scenario: Иконка при установке на Android

- **WHEN** пользователь устанавливает приложение на Android
- **THEN** на домашнем экране и в списке запущенных приложений отображается знак приложения
- **AND** стандартная иконка Flutter не отображается

#### Scenario: Иконка web-сборки

- **WHEN** пользователь открывает web-сборку приложения
- **THEN** вкладка браузера показывает знак приложения вместо стандартной иконки Flutter
- **AND** добавление web-сборки на домашний экран использует тот же знак

#### Scenario: Иконка исполняемого файла Windows

- **WHEN** пользователь запускает собранное приложение на Windows
- **THEN** ярлык и окно приложения используют знак приложения

### Requirement: Знак запуска пригоден для генерации иконок

Изображение знака, из которого генерируются иконки платформ, MUST быть квадратным, а знак MUST занимать кадр без прозрачных полей вокруг. Файл-первоисточник знака MUST храниться в репозитории отдельно от изображения, используемого для генерации иконок.

#### Scenario: Кадрирование исходного изображения

- **WHEN** исходное изображение знака имеет непропорциональные размеры или прозрачные поля вокруг знака
- **THEN** для генерации иконок используется квадратное изображение, обрезанное по границам знака
- **AND** знак не уменьшается полями и не обрезается

#### Scenario: Файл-первоисточник знака

- **WHEN** разработчику требуется повторно сгенерировать иконки
- **THEN** в репозитории доступны и изображение для генерации, и исходный экспорт знака
- **AND** исходный экспорт знака сохраняется без изменения размеров и содержимого

### Requirement: Иконка Android адаптирована к форме маски

Иконка запуска Android MUST содержать передний план с прозрачными полями, внутри которого знак целиком помещается в гарантированную зону, и сплошной фон. Для версий Android ниже 8.0 MUST поставляться обычная иконка той же формы знака.

#### Scenario: Иконка на Android 8.0 и новее

- **WHEN** система применяет к иконке маску выбранной формы
- **THEN** знак остается полностью видимым внутри маски
- **AND** ни одна значимая часть знака не обрезается

#### Scenario: Иконка на Android ниже 8.0

- **WHEN** приложение установлено на Android версии ниже 8.0
- **THEN** иконка запуска отображается в форме знака приложения

#### Scenario: Маска не создает видимую рамку

- **WHEN** система применяет маску и подставляет фон иконки
- **THEN** фон иконки совпадает с фоном знака
- **AND** вокруг знака не появляется заметная рамка или второй контур

### Requirement: Ресурсы иконок воспроизводимы

Иконки платформ MUST генерироваться из одного изображения знака и MUST быть зафиксированы в репозитории. Повторная генерация MUST обновлять иконки всех поддерживаемых платформ из того же изображения.

#### Scenario: Единый источник иконок

- **WHEN** знак приложения изменяется
- **THEN** обновление выполняется заменой изображения знака и повторной генерацией
- **AND** иконки платформ не редактируются вручную по отдельности

#### Scenario: Сборка не зависит от генерации

- **WHEN** сборка приложения выполняется без запуска генератора иконок
- **THEN** платформы используют ранее сгенерированные иконки
- **AND** в собранном приложении отсутствует стандартная иконка Flutter

#### Scenario: Инструмент генерации не попадает в сборку

- **WHEN** приложение собирается в release-конфигурации
- **THEN** инструмент генерации иконок не входит в состав приложения
