# Proposal

## Why

Приложение устанавливается с иконкой Flutter по умолчанию: на домашнем экране и в списке запущенных приложений Android, в ярлыке web-сборки и в файле `budget_tracker.exe` на Windows оно выглядит как демонстрационный проект и не опознается среди других. Знак приложения уже подготовлен в `assets/icon/icon.png`, но не подключен к платформам, поэтому установленное приложение не имеет собственного узнаваемого облика.

## What Changes

- Знак приложения становится иконкой запуска для всех поддерживаемых платформ проекта: Android, web и Windows. Иконка остается единой: один исходный файл, разные представления, требуемые платформами.
- Исходная картинка приводится к квадратному виду: экспорт `assets/icon/icon.png` имеет портретный формат 768×1152 с прозрачными полями, а знак занимает только центральную часть. Прозрачные поля обрезаются по границам знака, результат сохраняется квадратным мастером `assets/icon/app_icon.png` (1024×1024). Исходный экспорт сохраняется как файл-первоисточник и иконкой не является.
- Для Android добавляется adaptive-иконка: знак размещается в центре переднего плана с прозрачными полями внутри гарантированной зоны, фон задается сплошным цветом, совпадающим с собственным фоном знака. Версии Android до 8.0 получают обычные (legacy) иконки той же формы.
- Иконки генерируются инструментом `flutter_launcher_icons` из мастера одной командой; сгенерированные ресурсы сохраняются в репозитории, чтобы сборка не зависела от запуска генератора.
- Иконка запуска остается системным ресурсом и не используется внутри интерфейса приложения: экраны не получают декоративной графики (см. требование о визуальном приоритете сумм).

Не входит в изменение: логотип и знак внутри UI, иконка для iOS и других платформ, отсутствующих в проекте, изменение названия приложения.

## Capabilities

### New Capabilities

Новые capability не вводятся: изменение дополняет существующее визуальное направление приложения.

### Modified Capabilities

- `app-visual-theme`: новое требование о собственном знаке запуска приложения — единый источник знака, генерация иконок для Android (включая adaptive), web и Windows, отсутствие иконки Flutter по умолчанию и запрет использования знака внутри UI.

## Impact

- `assets/icon/` — исходный экспорт, квадратный мастер и передний план adaptive-иконки.
- `android/app/src/main/res/` — `mipmap-*/ic_launcher.png`, `mipmap-anydpi-v26/ic_launcher.xml`, `drawable-*/ic_launcher_foreground.png`.
- `web/` — `favicon.png`, `icons/Icon-192.png`, `icons/Icon-512.png`, `icons/Icon-maskable-*.png`, цвета в `manifest.json`.
- `windows/runner/resources/app_icon.ico`.
- `pubspec.yaml` — dev-зависимость `flutter_launcher_icons` с конфигурацией генерации.
- OpenSpec: delta-спека `app-visual-theme`. Отдельная запись ADR не требуется: решение касается ресурсов оформления, не меняет архитектуру и не противоречит ADR-0001 (единый облик и узнаваемость приложения поддерживают концепцию).
