# Proposal

## Why

Проект пока остаётся шаблонным Flutter-приложением и не имеет согласованного фундамента для хранения данных, управления состоянием и локализации. Подключение этих базовых возможностей сейчас позволит следующим изменениям добавлять функции учета личных финансов без повторного пересмотра структуры приложения.

## What Changes

- Добавляется инфраструктурный слой локального SQLite-хранилища на основе `Drift` и `drift_flutter` с поддержкой генерации кода.
- Добавляется корневой `ProviderScope` и базовая интеграция `flutter_riverpod` для размещения состояния и зависимостей приложения.
- Включается стандартная Flutter-локализация через `flutter_localizations`, `intl` и generated localization resources для русского (`ru`) и английского (`en`) языков.
- Русский язык используется как fallback locale, если локаль устройства не поддерживается.
- Определяются границы между UI, состоянием и data access для следующих изменений.
- Не добавляются таблицы доходов, расходов, категорий или другие предметные модели бюджета.
- Не добавляются серверная синхронизация, авторизация или новые пользовательские экраны.

## Capabilities

### New Capabilities

- `app-foundation`: базовые возможности локального хранения, управления состоянием и локализации Flutter-приложения.

### Modified Capabilities

Нет.

## Impact

Изменения затронут `pubspec.yaml`, точку входа приложения, конфигурацию Flutter localization, `l10n.yaml`, русские и английские ARB-ресурсы, новые файлы data/state слоев и widget/unit tests. Появятся runtime-зависимости `drift`, `drift_flutter`, `flutter_riverpod`, `flutter_localizations`, `intl`, а также dev-зависимости `drift_dev` и `build_runner`. Существующий шаблонный counter flow будет заменен или адаптирован только настолько, чтобы проверить работу нового фундамента.
